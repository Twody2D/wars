# Карточка игры в консоли Яндекс Игр

Картинки: `build/store/` (не в git, пересоздать — см. «Картинки» внизу).

## Общее

| Поле | Значение |
| --- | --- |
| Поддерживаемые платформы | Компьютер, мобильные (телефон и планшет) |
| Ориентация | Горизонтальная (в портрете игра просит повернуть экран) |
| Игра переведена на | Русский, English |
| Возрастной рейтинг | 6+ (мультяшные бои, без крови) |
| Категории | Казуальные, Аркады, Для мальчиков (стратегий и tower defense в списке Яндекса нет) |
| Облачные сохранения | Да |

**Теги** — выбирать из списка консоли, в порядке важности (у конкурентов «Битва за эволюцию» и Age of Heroes ~30 тегов, берём те, что про нас):
1. Про игру: `защита башни`, `битва`, `зомби`, `скелеты`, `монстры`, `армия`, `средневековые`, `стратегия`, `пиксельные`, `2D`, `милые`, `боссы`
2. Про аудиторию: `для детей`, `для подростков`, `для мальчиков`
3. Технические (их ставят все): `бесплатные`, `браузерные`, `без регистрации`, `без скачивания`, `на русском`, `мобильные`, `десктоп`, `для компьютера`, `на весь экран`, `в хорошем качестве`

Каких-то тегов в списке может не оказаться — берём ближайшие по смыслу. Чужие бренды (майнкрафт, зверополис и т. п.) не ставим: модерация может снять за вводящие в заблуждение теги.

**Ключевые слова** (≤ 100): `зомби, скелеты, армия, сражение, защита башни, tower defense, битва, стратегия, прокачка, боссы`

**Комментарий разработчика** (для модерации):

> Язык определяется через SDK при запуске (environment.i18n.lang): русский для ru/be/kk/uk/uz, остальные — английский; переключателя языка в игре нет. Правила — кнопка «?» в главном меню («Как играть»), на 1-м уровне — подсказки со стрелкой. Реклама: rewarded — бустеры «×2 скорость» и «+15 еды» в бою и «×2 монеты» после боя (награда только после полного просмотра); interstitial — при выходе из боя; sticky-баннер показывает сама игра через API (showBannerAdv). На время рекламы и при сворачивании игра на паузе, звук выключен. Прогресс — облачные сохранения SDK. Покупки — вкладка «Магазин» (и «+» у монет): цены и валюта из каталога SDK; монеты выдаются и потребляются (consumePurchase), «Набор новичка», «Без рекламы» и «Золотая кирка» — постоянные, восстанавливаются через getPurchases при каждом запуске; необработанные покупки выдаются при запуске и при открытии магазина. «Без рекламы» отключает interstitial и sticky-баннер (hideBannerAdv сразу после покупки и при каждом запуске), rewarded остаются по желанию игрока. Покупки хранятся и в облачном сохранении.

## Инап-покупки (T20)

Консоль → «Инап-покупки»: сначала **запрос на подключение** в «Настройках» (без одобрения модерация не пройдёт), потом товары. ID — ровно как в таблице (игра ищет их в каталоге; товара нет в каталоге — карточка скрыта). Названия — как в игре (1.13.6), описание — что реально выдаётся (1.13.5). Цены (Twody, 01.10, в консоли): набор 19, без рекламы 79, кирка 99, монеты 12 / 39 / 99 ян (≈ $0.75 / 3 / 4 / 0.5 / 1.5 / 4). Бейджи: «−60%» у набора (гоблин 5 000 + 5 000 монет ≈ 49 ян по цене мешка), «+20%» у сундука (выгода над мешком 23%). Картинки товаров — `art/ui/v3/shop/art_*.svg` (выгрузить в PNG 256×256).

| ID | Название ru / en | Описание ru / en | Тип |
| --- | --- | --- | --- |
| `starter_pack` | Набор новичка / Starter Pack | Шахтёр-гоблин и 5 000 монет. Один раз / Goblin Miner and 5,000 coins. Once | постоянный (не потребляется), повторно не продаётся |
| `no_ads` | Без рекламы / No Ads | Навсегда убирает рекламу: между экранами и баннер. Реклама за награду остаётся по желанию / Removes ads forever: between screens and the banner. Reward ads stay optional | постоянный |
| `gold_pickaxe` | Золотая кирка / Golden Pickaxe | ×2 монеты за каждый бой навсегда / ×2 coins for every battle forever | постоянный |
| `coins_small` | Горсть монет / Handful of Coins | 2 000 монет / 2,000 coins | потребляемый |
| `coins_bag` | Мешок монет / Bag of Coins | 8 000 монет / 8,000 coins | потребляемый |
| `coins_chest` | Сундук монет / Chest of Coins | 25 000 монет / 25,000 coins | потребляемый |

**Файлы для консоли:** `build/store/products/products.csv` (загрузить кнопкой «Загрузить CSV-файл»; перед загрузкой сверить заголовки столбцов с примером файла из консоли) и картинки товаров `build/store/products/<id>.png` (256×256). Пересоздать: `"$GODOT" --headless --path . -s res://tools/export_products.gd` (названия — из локализации, как в игре; описания — в скрипте; цены — `mock_price` в `data/shop/*.tres`).

**Валюта (сверено с докой 01.10):** цены в консоли — целым числом в портальной валюте Яндекса (яны, единый баланс игрока; курс к рублю плавающий, в других странах — по региональным коэффициентам). Рубли в игре писать нельзя: игра показывает цену из каталога SDK — `priceValue` + иконка `getPriceCurrencyImage('medium')`, без иконки — строка `price` («49 YAN»). Модерация подменяет валюту тестовой — у нас она сменится сама.

«Монеты за рекламу» (+500 раз в 15 минут) — rewarded-реклама, в консоль не заносится. Бейджи «−60%», «ХИТ», «+25%» — тексты `SHOP_STICKER_STARTER`, `SHOP_RIBBON_*` в `localization/translations.csv`: при других ценах поправить, чтобы оставались правдой.

Тестовые покупки — только в черновике и только сейчас, когда обработка уже в коде (иначе останутся необработанные платежи).

- `build/store/shot_*.png` — скриншоты 1920×1080: бои `battle_meadow` (Король зомби у щита), `battle_cave` (Каменный голем), `battle_slimes` (ур. 6, метеор), `battle_goblins` (ур. 14, метеор), `battle_spiders` (ур. 8); экраны `upgrades`, `shop`, `menu`, `map`. **Яндекс: не меньше 70% скриншотов — геймплей** → загружать 5 боёв + улучшения + магазин (5 из 7), меню и карту — нет. **Только горизонтальные**: «загружайте только скриншоты, соответствующие выбранной ориентации», игра горизонтальная; минимум 2 на каждую платформу (ПК, мобильные).
