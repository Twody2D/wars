# Требования Яндекс Игр — полный чек-лист

Источник: https://yandex.ru/dev/games/doc/ru/concepts/requirements (сверено 29.09.2026; номера пунктов — оттуда). Несоответствие даже одному обязательному пункту = отклонение. Раздел 6 — рекомендации, но влияют на продвижение.

## 1. Техника

- [ ] **1.1** SDK Яндекс Игр подключён.
- [ ] **1.2** Никаких сторонних регистраций — только вход через Яндекс ID из SDK. **1.2.1** Вход — по действию игрока с понятной выгодой («войди, чтобы сохранить прогресс»), не навязывать. **1.2.2** Гостевой режим обязателен, прогресс гостя сохраняется.
- [ ] **1.3** Звук выключается при потере фокуса.
- [ ] **1.4** Платежи только через SDK, никаких внешних покупок.
- [ ] **1.6** Игра работает на всех заявленных типах устройств (в черновике отмечать только проверенные; ТВ не заявлять без нужды — там свои правила 1.6.3: стрелки, «Назад»/«ОК», без инапов и ссылок на свои игры).
- [ ] **1.6.1 Телефон:** полный экран; экранная клавиатура появляется при фокусе поля ввода; управление жестами; **нет системного медиаплеера** (не играть звук через `<audio>`/`<video>` — только WebAudio, как в Godot); **нет уведомления про WebGL** при открытии; долгий тап не выделяет и не открывает меню.
- [ ] **1.6.2 ПК:** поле тянется на доступное место; соотношение сторон ≤ 2:1; мышь + клавиатура, независимо от раскладки (`physical_keycode`); нет системного медиаплеера; **не занимать системные сочетания клавиш** (Ctrl+W/T/R/N, F5, F11, Alt+F4, Ctrl+Tab…); нет выделения и контекстного меню.
- [ ] **1.7** Нет абсолютных URL на S3 и т. п. в коде — только относительные пути.
- [ ] **1.8** Элементы интерфейса удобного размера для экрана.
- [ ] **1.9** Прогресс сохраняется сразу (или по кнопке) и переживает перезагрузку и поворот.
- [ ] **1.10** Ресайз и поворот: **1.10.1** ничего не обрезано; **1.10.2** нет полосы прокрутки браузера и swipe-to-refresh (своя прокрутка внутри игры можно); **1.10.3** нет наложений; **1.10.4** играется одной рукой, главный экран без прокрутки.
- [ ] **1.11** Облачные сохранения → отметить «Использует облачные сохранения» в черновике.
- [ ] **1.12** Есть монетизация: реклама или инапы (или отметка, что монетизации нет).
- [ ] **1.13 Инапы:** обработка (consume) подключена; валюта портала из SDK; **1.13.3** прогресс с покупками хранится на сервере (облако) и доступен на других устройствах; **1.13.4** у каждой покупки цена числом + валюта портала; **1.13.5** описание = то, что реально выдаётся; **1.13.6** список покупок в игре = списку в консоли (неактивных в игре нет).
- [ ] **1.14** Нет ошибок, зависаний, вылетов в игре, при повороте, рекламе, сворачивании.
- [ ] **1.15** Игра закончена: нет «в разработке», заглушек, неработающих кнопок.
- [ ] **1.16** Рекламные блоки не модифицировать; свои кнопки «показать полноэкранную рекламу» запрещены (rewarded-кнопка с наградой — можно, см. 4.5).
- [ ] **1.18** Работает с любого URL (Яндекс открывает игру с разных адресов) — пути относительные.
- [ ] **1.19** SDK по документации: инициализация; `LoadingAPI.ready()` когда можно играть; `GameplayAPI.start/stop` в правильные моменты; `game_api_pause/resume` обработаны.
- [ ] **1.20** Браузеры: Яндекс, Chrome, Firefox, Opera, Safari, приложение Яндекс; Windows 7+, macOS; Android 5+, iOS 9+ (на практике проверить Safari/iOS — WebGL2 и звук после первого касания).
- [ ] **1.21** Распакованный размер ≤ 100 МБ. **1.22** `index.html` в корне, имена без пробелов и кириллицы.
- [ ] **1.23** Интерактивный ИИ в игре запрещён (чат-боты, генерация на лету); заранее сгенерированные ИИ-материалы можно.
- [ ] **1.24** Обновления сохраняют суть игры — другую игру под видом обновления загружать нельзя.

## 2. Игровой опыт

- [ ] **2.1** Игра доделана по контенту, удобству и геймплею (оценивается вручную).
- [ ] **2.2** Управление описано в игре или в поле «Как играть».
- [ ] **2.3** Жанр совпадает с заявленным. **2.4** Есть хотя бы одна полноценная игровая механика.
- [ ] **2.7** Контент соответствует возрастному рейтингу.
- [ ] **2.8** Сложность нарастает, есть понятная история или сеттинг. **2.9** Основной контент ≥ 10 минут или есть мотивация переигрывать.
- [ ] **2.13** Рейтинг игры > 30; если ≤ 30 три недели — снимают с публикации (следить после релиза).
- [ ] **2.14** Язык — автоопределение через SDK при запуске.

## 3. Содержание

- [ ] **3.4.2** Без чёрной магии; в гаданиях — без покупок. **3.4.3** Без реалистичного насилия и жестокости к детям и животным.
- [ ] **3.4.4** Без политики, политиков, **реальных конфликтов и войн**. Мультяшная фэнтези-битва — можно, но слова «война» и военная символика реального мира — риск; в текстах лучше «битва», «сражение».
- [ ] **3.4.5** Без религии и религиозных символов. **3.4.6** Без «предсказаний» о жизни, здоровье, смерти игрока.
- [ ] **3.5** Права на все материалы у разработчика (CC0-ассеты — вести список источников); лицензии можно показать текстом в игре.
- [ ] **3.6** Не дубль игры из каталога или своей же игры; сиквел — с полной переработкой.
- [ ] **3.7** Нельзя выиграть реальные деньги, призы, товары, сертификаты.
- [ ] **3.9** Видео в игре — без обращения к внешним ресурсам; встраивать YouTube нельзя.

## 4. Реклама

- [ ] **4.1** Только через SDK; никакой сторонней рекламы, рекламных картинок и текстов.
- [ ] **4.2** После рекламы игра продолжается с того же места.
- [ ] **4.3** Рекламные блоки в ориентации игры.
- [ ] **4.4** Реклама не мешает — только в логических паузах.
- [ ] **4.5** Rewarded — по желанию, по кнопке; **4.5.1** на кнопке видно, что это реклама и что за награда; **4.5.2** награда — бонус, не нужный для прохождения.
- [ ] **4.6** Дополнительная реклама — только sticky-баннеры; свои RTB-баннеры запрещены.
- [ ] **4.7** Во время полноэкранной и rewarded рекламы — пауза игры и звука.

## 5. Страница игры и промо

- [ ] **5.1.1** Материалы — из этой игры; одни и те же материалы нельзя использовать для разных игр. **5.1.1.2** Скриншоты ≥ 70% реального геймплея (≤ 30% рамки и эффекты). **5.1.1.3** Видео ≥ 70% времени — реальный геймплей.
- [ ] **5.1.2** Материалы показывают суть, фишки, отличия.
- [ ] **5.1.3** Название в игре и во всех материалах черновика одинаковое (для каждого языка). **5.12** Название уникально в каталоге на всех языках.
- [ ] **5.2** Заполнены все обязательные поля: название, «Об игре», «Как играть», версия, категория, иконка, обложка, архив, платформы, ориентация, скриншоты.
- [ ] **5.3** Длины, размеры, форматы — по требованиям полей. **5.4** Теги и ключевые слова по теме игры.
- [ ] **5.6** Иконка и обложка — не скриншоты. **5.9** Чёрный фон — только если он часть игры, а не поля от масштабирования.
- [ ] **5.11** Без повторов символов ради длины; тексты разных полей не дублируют друг друга.

## 6. Рекомендации (не обязательны, но влияют на продвижение)

- [ ] **6.1** Контактный email разработчика. **6.2** Кнопка выключения звука. **6.3** Пауза.
- [ ] **6.4** Консоль DevTools без ошибок.
- [ ] **6.5** В названии нет «игра»/«game» (если не часть названия). **6.6** Название короткое.
- [ ] **6.7** Нет бесполезных кнопок (например, «Выход» в главном меню — в браузере выходить некуда).
- [ ] **6.8** Обучение в сложных играх. **6.9** Ручной выбор языка (если есть) — флаги/самоназвания языков.

## 8. Тексты и медиа (везде: игра, карточка, картинки)

- [ ] **8.2.1** Орфография и пунктуация. **8.2.2** Тексты и название не вводят в заблуждение (описывают реальные механики). **8.2.3** Игровые тексты переведены на заявленные языки. **8.2.4** Без мата на любом языке.
- [ ] **8.3.1** Картинки и видео качественные: без артефактов, пересветов, сплошных рамок, обрезанного текста. **8.3.2** Отражают суть, а не случайные картинки.
- [ ] **8.3.3** **Без рамок и скруглённых углов** на иконке, обложке, скриншотах — скругление делает сам каталог.
- [ ] **8.3.4** Без системного интерфейса (статус-бар, батарея) и интерфейса Яндекс Игр (бейджи, рейтинг). Игровой UI на скриншотах — можно, на иконке и обложке — нет.
- [ ] **8.3.5–8.3.7** Без эротики, дискриминации и прочего запрещённого; безопасно и по возрасту.
- [ ] **8.4.1** Ссылки — только на свои игры в каталоге и только через SDK. **8.4.2** Никаких внешних ссылок (сайты, магазины, чужие игры, скачивание файлов); логотип бренда без URL можно. **8.4.3** Соцсети — только сообщество игры, где упомянуты Яндекс Игры и нет внешних ссылок. **8.4.4** Никаких автоперенаправлений на внешние сайты.
