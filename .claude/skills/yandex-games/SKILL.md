# Яндекс Игры: SDK, требования, консоль

> В этом репозитории (Mine Rush) шаблоны уже внедрены: мост — `web/custom_shell.html`, платформа — `scripts/autoload/platform.gd` и `scripts/platform/`, boot — `scripts/ui/boot.gd`, проверка — `tools/check_build.py`, `tools/browser_check.py`, поддельный SDK — `tools/fake_yandex_sdk.js`. Таблица «Файлы скилла» ниже — про глобальную копию скилла на ПК Twody.

Проверено на Mine Rush (Godot 4.7, 2D, ru/en, 09.2026). Требования меняются — при сомнении сверяться с https://yandex.ru/dev/games/doc/ru/concepts/requirements и https://yandex.ru/dev/games/doc/ru/sdk/sdk-about.

Шаблоны завязаны на имена из Mine Rush (`GameState.sound_on`, `GameState.merge_cloud`, лидерборд `stars`, ru/en) — при переносе поправить. Каждый JS-вызов моста отвечает через callback, в том числе по таймауту и ошибке — игра никогда не зависает, если SDK не загрузился (локально, адблок).

## Архитектура (как делать)

- Всё общение с SDK — только через автозагрузку `Platform`. В редакторе и тестах — `PlatformMock`, в вебе — `PlatformYandex` (без SDK работает офлайн: rewarded отказывает, облака нет).
- `JavaScriptBridge.eval` не использовать (только с константными строками, лучше вообще нет): `JavaScriptBridge.get_interface("YG")` + `create_callback`. Ссылки на callbacks хранить в полях, иначе их соберёт GC.
- `/sdk.js` грузить только не на localhost (иначе 404 в консоли при локальном запуске).
- Сохранение: локально сразу (`user://`), в облако — `player.setData({save: json})`; при запуске брать облако, если в нём больше прогресса.

## Правила, которые легко нарушить

1. **Язык (2.14)** — только из `ysdk.environment.i18n.lang`, при запуске (в boot, до меню), не после «Играть». Переключателя языка в игре нет, в сохранение язык не писать. Резерв: ru для `ru, be, kk, uk, uz`, остальным en. Индикатор 文 в debug-панели должен позеленеть на загрузке.
2. **Реклама (4.x)** — только через SDK и только в паузах (переход между экранами, конец боя), никогда во время активной игры. Fullscreen: частоту решает платформа — просто вызывать в точках перехода. Rewarded: награда только после `onRewarded` + `onClose`; закрыл раньше — награды нет, кнопка снова активна. Rewarded-кнопки подписаны значком видео и дают бонус, а не обязательный ресурс.
3. **Пауза и звук (1.3, 4.7)** — при рекламе, `game_api_pause`, потере фокуса вкладки: игра на паузе, шина Master замьючена. После рекламы/фокуса — звук вернуть. Клик по чёрным полям вокруг холста не должен снимать фокус (см. `mousedown` в шаблоне).
4. **LoadingAPI.ready()** — когда игра реально готова к взаимодействию (после boot). **GameplayAPI start/stop** — начало и конец активного геймплея (бой / пауза, меню, реклама).
5. **Лидерборд** — необязателен. `setScore` только для авторизованных: проверять `ysdk.isAvailableMethod('leaderboards.setScore')`, иначе ошибка в консоли у гостей. Не чаще 1 раза в секунду. Техническое имя в коде = имени в консоли, иначе 404.
6. **Экран (1.6)** — холст на всё окно, но не шире 2:1 (остальное — чёрные поля), поле до края. Нет прокрутки, выделения, контекстного меню, долгого тапа, зума. Горизонтальная игра в портрете показывает «Поверни устройство» и ставит паузу.
7. **Архив (1.21–1.22)** — `index.html` в корне zip, имена файлов латиницей без пробелов. Консоль показывает размер **распакованного** архива (у Mine Rush zip 8 МБ → «22.65 Mb»: wasm 18 МБ сжимается в 4.4) — это нормально, лимит 100 МБ.
8. **«Как играть» (2.2)** — отдельное окно с правилами (кнопка «?» в меню) + обучение на первом уровне.

## Инап-покупки (payments)

- Запрос на подключение покупок — в консоли, «Инап-покупки → Настройки», **отправить как можно раньше**: без одобрения игра с покупками не пройдёт модерацию. Там же должно стать «Покупки включены».
- Методы: `ysdk.payments.getCatalog()` (товары с ценой и иконкой валюты), `purchase({id, developerPayload})`, `getPurchases()`, `consumePurchase(purchaseToken)`.
- Расходуемые (монеты): выдать товар → `consumePurchase`. Постоянные («Без рекламы», «×2 монеты навсегда»): не потреблять, проверять через `getPurchases()` при запуске — переживают переустановку.
- **При каждом запуске** проверять необработанные покупки (`getPurchases`), выдать и потребить — обязательно для модерации. Тестовые покупки делать только после того, как обработка готова в коде, иначе останутся необработанные платежи и модерация не пройдёт.
- Валюта портала — яны; название и иконку валюты брать из SDK (`IProduct`: `price`, `priceCurrencyCode`, `getPriceCurrencyImage()`), цену показывать как «<цена> <валюта>», свою иконку яна не рисовать.
- Покупки работают и без входа, но стоит предложить войти в аккаунт (иначе покупка привязана к устройству).
- «Без рекламы» убирает только fullscreen; rewarded остаётся по желанию игрока. Игры с инапами Яндекс чаще берёт в «Рекомендованное».

## Порядок работы над новой игрой

1. Скопировать шаблоны, поправить имена, подключить `Platform` и boot.
2. Экспорт: `"$GODOT" --headless --path . --export-release "Web" build/web/index.html`, затем `py -3.14 tools/check_build.py`.
3. Локально: `py -3.14 -m http.server 8060 --bind 127.0.0.1 -d build/web`, открыть, консоль без ошибок. Мост с поддельным SDK: скопировать `fake_yandex_sdk.js` в `build/web/sdk.js`, открыть `http://fake.test:8060/` через `browser_check.py` (он мапит fake.test на localhost). **Удалить `sdk.js` перед упаковкой.**
4. Twody загружает `build/game.zip` в черновик → проверка по списку ниже.
5. Карточка игры и картинки — скилл `store-assets`, тексты — шаблон ниже.

## Консоль разработчика (делает Twody, объяснить по шагам)

- **Монетизация**: подключить в консоли; если на странице есть «Статистика РСЯ» — уже подключена. Реклама в коде без ID блоков — вызовов SDK достаточно.
- **Реквизиты** (физлицо / самозанятый): «Расчётный счёт» = «Номер счёта получателя» из банка (20 цифр, у физлица начинается на 40817, у ИП — 40802), «БИК» = БИК банка получателя. Корр. счёт не нужен.
- **Sticky-баннеры** — включать, это заметный доход (Яндекс: +30…350% тем, кто не использовал). Для горизонтальной игры: портрет — «Внизу» (там всё равно экран «поверни»), альбомная — **«Справа»** (отнимает ширину, которой у телефона в альбомной с запасом; «Внизу» отняло бы высоту), десктоп — вкл., «Использовать API» — выкл. Проверить вёрстку при узком окне (~16:10): ничего не перекрыто.
- **Лидерборд**: техническое название = константа в коде, числовой, по убыванию, сделать основным.
- **Черновик**: загрузить zip → «Обработка → Проверка → Готово» → «Дебаг».
- **Игра переведена на**: все языки из переводов — модерация проверит каждый.

## Проверка черновика (debug-панель, кеш очищен)

| Проверка | Ожидание |
| --- | --- |
| Старт | Индикатор 文 зелёный на загрузке; `LoadingAPI.ready` вызван |
| SDK mocks → другой язык | Игра целиком на этом языке |
| Rewarded-кнопки | Реклама, игра на паузе, звука нет; награда только после полного просмотра |
| Закрыть rewarded раньше | Награды нет, кнопка активна |
| Переход между экранами | Fullscreen (не каждый раз — частоту решает Яндекс) |
| Свернуть/сменить вкладку | Пауза, звук выключен |
| Пройти уровень, перезагрузить | Прогресс на месте (облако) |
| Поворот телефона, ресайз окна | Нет обрезки и наложений |
| F12 → Console | Нет красных ошибок |

## Карточка игры (шаблон)

Поля: название (≤ 50, одинаковое везде и уникальное), короткое описание (≤ 70), SEO-описание (≤ 160), «Об игре» (≤ 1000), «Как играть» (≤ 1000) — для каждого языка. Стиль как у топа каталога: вопрос-крючок, на «ты», разделы КАПСОМ с эмодзи, выгоды игрока, поисковые слова. Теги — только из списка консоли, без чужих брендов. Возраст, категории, облачные сохранения — да.

**Комментарий для модерации** (адаптировать):
> Язык определяется через SDK при запуске (environment.i18n.lang): русский для ru/be/kk/uk/uz, остальные — английский; переключателя языка в игре нет. Правила — кнопка «?» в главном меню, на 1-м уровне — обучение. Реклама: rewarded — <что даёт> (награда только после полного просмотра); interstitial — <где>. На время рекламы и при сворачивании игра на паузе, звук выключен. Прогресс — облачные сохранения SDK.
